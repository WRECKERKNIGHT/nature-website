# Nature Explorer 🍃

A cinematic, single-page website dedicated to the beauty and importance of the natural world. Built with a glassmorphism aesthetic, GSAP scroll-driven animation, and a live nature video background.

## ✨ Features

- **Full-screen ambient video background** — a seamless looping nature video with a cinematic gradient overlay
- **Glassmorphism UI** — frosted-glass cards, buttons, and navigation over living imagery
- **GSAP scroll animations** — staggered 3D card entrances, parallax hero load, and weightless floating cards
- **Interactive micro-interactions** — water ripple effect on click, leaf cursor that trails your pointer, magnetic hover scaling
- **Rich content** — thriving ecosystems, natural resources, nature-protecting communities, and conservation messaging

## 🛠 Tech Stack

- [Vite](https://vite.dev) — fast dev server and optimized production builds
- Vanilla JavaScript (ES modules)
- [GSAP](https://gsap.com) + ScrollTrigger via CDN
- [Google Fonts](https://fonts.google.com) — Outfit
- YouTube IFrame API for the looping background video

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Production build
npm run build

# Preview the production build
npm run preview
```

## 📁 Project Structure
